# Shift and Water Calendar

Лёгкое Android-приложение (Java, XML-layouts, без Jetpack Compose) для
отслеживания циклического графика работы (например, 2/2) и события
"привоз воды".

## Почему XML, а не Compose

Как и обсуждалось: Compose + `material-icons-extended` заметно увеличивают
время холодного старта из-за индексации тысяч иконок и рантайм-компиляции
composable-функций в debug-режиме. Здесь используется классический подход:

- **Никакого Compose** — только `View`/`RecyclerView`/`ViewGroup`.
- **Никакого `material-icons-extended`** — все иконки — это по 5–10 строк
  `VectorDrawable` (стрелки навигации, шестерёнка настроек), которые
  Android парсит мгновенно.
- **Системный шрифт** (`sans-serif`) — не грузятся кастомные `.ttf`.
- **Минимум библиотек**: `appcompat`, `material` (только ради `FloatingActionButton`
  и темы), `recyclerview`, `cardview`. Никаких Room/Retrofit/Glide — они не нужны.
- **Хранение настроек** — `SharedPreferences`, без базы данных и её инициализации.
- **release-сборка** с `minifyEnabled true` и `shrinkResources true` — код и
  ресурсы обрезаются R8.

Всё это вместе даёт классический для XML-layouts холодный старт
(обычно значительно быстрее 500 мс на современных устройствах, но точная
цифра зависит от устройства — это нужно будет измерить профилировщиком
Android Studio на реальном телефоне).

## Структура проекта

```
app/src/main/java/com/shiftcalendar/app/
├── model/
│   ├── ShiftType.java       — описание типа смены (имя, иконка, признак работы)
│   ├── ShiftConfig.java    — дата начала + последовательность смен
│   └── DayStatus.java      — рассчитанный тип смены для конкретной даты
├── logic/
│   └── ShiftCalculator.java — формула: индекс = (target - start) % cycleLength
├── data/
│   └── PrefsRepository.java — SharedPreferences: сохранение/чтение настроек
└── ui/
    ├── MainActivity.java     — главный экран, навигация по месяцам, диалог настроек
    └── CalendarAdapter.java  — RecyclerView-адаптер: строки недель + номер недели (ISO)
```

Юнит-тест `ShiftCalculatorTest` (в `app/src/test/...`) проверяет формулу,
включая даты **до** точки отсчёта (отрицательный diff).

## Как открыть проект

1. Распакуйте архив.
2. Откройте папку `ShiftCalendar` в Android Studio (Meerkat/Koala или новее,
   AGP 8.5.2, Gradle 8.7 — Android Studio сама предложит сгенерировать
   `gradle-wrapper.jar`, если его нет; либо выполните `gradle wrapper` вручную,
   если у вас установлен системный Gradle).
3. Дождитесь синхронизации Gradle — она подтянет зависимости с `google()` и
   `mavenCentral()`.
4. Запустите конфигурацию `app` на устройстве/эмуляторе (minSdk 26 / Android 8.0+).

## Что реализовано

- Поддержка произвольных типов смен с собственными иконками (эмодзи) и названиями.
- Формула расчёта статуса дня, корректно работающая для дат до и после точки отсчёта.
- Сетка календаря 7×N с номерами недель (ISO 8601) в левой колонке.
- Индикаторы: иконка смены под числом (☀️, 🌙, 🏠, 💧 и др.), цветная обводка для рабочих дней.
- Навигация "Вперёд/Назад" по месяцам.
- Сохранение настроек в формате JSON внутри SharedPreferences.
- Диалог настроек: ввод произвольной последовательности смен (через У, Н, В, Д, П) и выбор даты начала.
- Навигация жестами (взмах влево/вправо) для переключения месяцев.
- Виджет на главный экран: показывает текущую смену, наличие привоза воды сегодня и отсчет дней до следующей рабочей смены.
